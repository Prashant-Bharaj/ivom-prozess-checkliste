# IVOM-Prozess-Checkliste

Prototyp aus dem Mini-Hackathon beim Ophthalmologen-Kongress (25.–26.09.2026).

**Live:** https://niclasbayer.github.io/ivom-prozess-checkliste/

Der IVOM-Tagesablauf als abhakbare Checkliste über fünf Stationen (Anmeldung,
Voruntersuchung, OP-Vorbereitung, OP, Entlassung) mit getrennten Rollen für Empfang,
MFA und Ärztin/Arzt. Jeder Haken zeigt, wer ihn gesetzt hat; Augenseite und
Infektionsausschluss sind an jeder Station eigene Pflichtpunkte, damit im
Behandlungszimmer sofort sichtbar ist, was bereits bestätigt wurde.

React + Vite, Zustand im localStorage. Alle Beispieldaten sind **synthetisch** —
keine echten Patientendaten.

Lokal starten: `npm install && npm run dev` → http://localhost:8080
